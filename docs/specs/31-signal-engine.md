# SIGNAL ENGINE

Build an explainable signal engine.

Possible evidence:

```text
Trend alignment
Market structure
Momentum
Volatility
Price action
Support/resistance
Multi-timeframe alignment
```

Create a configurable setup-strength score.

Example:

```text
0–39   Weak
40–59  Moderate
60–74  Strong
75–100 Very strong
```

This is:

TECHNICAL SETUP STRENGTH

NOT:

WIN PROBABILITY.
